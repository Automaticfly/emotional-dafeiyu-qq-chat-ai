# 大肥鱼心情表情

按心脏模块记录的当前心情，在部分回复末尾附加一个 QQ 原生小黄脸。

- 默认概率：50%
- 只在文本回复中附加
- 命中后默认一半跟在最后一段对话末尾，一半在对话后独立发送
- 回复中已有表情时不会重复添加
- 文本里已有 `[微笑]` 这类显式表情时交给 face_convert 处理
- 心情优先使用 `heart_state.dynamic_mood`，没有时使用 `baseline_mood`
- 心情读取失败时使用默认可爱表情

配置项：

- `enabled`：启用/关闭
- `face_probability`：携带表情的概率，默认 `0.5`
- `inline_probability`：跟随最后一段对话的概率，默认 `0.5`
- `mood_umo`：读取心情的会话；留空跟随当前会话
- `mood_cache_seconds`：心情缓存秒数
- `heart_plugin`：心脏插件目录名

对应关系大致为：

- 开心/喜欢 → 呲牙、可爱、偷笑、微笑
- 害羞 → 害羞、可爱、亲亲
- 难过/委屈 → 快哭了、难过、委屈、流泪
- 生气/吃醋 → 发怒、撇嘴、难过、坏笑
- 担心/紧张 → 惊恐、难过、流汗
- 困/累 → 睡、哈欠、困
- 想念 → 爱心、亲亲、微笑
- 平静 → 微笑、可爱、茶
