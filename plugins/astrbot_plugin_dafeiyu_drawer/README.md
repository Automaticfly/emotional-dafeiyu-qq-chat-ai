# 大肥鱼抽屉

两个抽屉：

1. **表情包抽屉**：自动收藏主人相关表情包，随时抽一张发出来
2. **小事抽屉**：主人随口说「喜欢什么」「几点睡」「什么习惯」时，当场收好

## 小事抽屉

主人私聊说：

```text
我喜欢吃火锅
我一般 23 点睡
我习惯晚上喝牛奶
我对花生过敏
叫我小鱼
记住我周末喜欢去江边
```

插件会立刻提取成一条抽屉记录，不需要等到凌晨结算。

支持的类型：

| 类型 | 例子 |
|---|---|
| `preference` | 喜欢火锅 / 不喜欢香菜 |
| `schedule` | 通常 23 点睡 / 通常 8 点起床 |
| `habit` | 习惯晚上喝牛奶 |
| `fact` | 对花生过敏 / 生日 5 月 20 日 / 称呼：小鱼 |

只抓主人相关消息；没有配置主人时，只在私聊里抓。

### AI 注入

主人私聊时，插件会把最近/相关的抽屉内容注入 system prompt，让她自然记得。

- 最多 5 条，总字数约 200 字
- 群里不注入，避免向群友泄露
- 不会像背清单一样全部说出来

### 命令

```text
/抽屉                    查看抽屉状态和最近小事
/抽屉 找 <关键词>         搜索
/抽屉 记 <内容>           手动记一条
/抽屉 删 <编号>           删除一条
/抽屉 表情包 [关键词]     发一张收藏的表情包
```

### 工具

| 工具 | 说明 |
|---|---|
| `drawer_remember` | 把一件小事收进抽屉 |
| `drawer_search` | 搜索抽屉 |
| `drawer_sticker` | 发一张收藏的表情包 |

## 表情包抽屉

自动收藏：

- 主人私聊里发的 GIF / 小图
- 主人在群里发的 GIF / 小图
- 默认单张上限 1.5MB，最多 300 张
- 按 sha256 去重
- 只收主人相关，不收藏群友照片

存放目录：

```text
data/plugin_data/astrbot_plugin_dafeiyu_drawer/stickers/
```

发表情包：

```text
/抽屉 表情包
/抽屉 表情包 猫
```

## 数据

```text
data/plugin_data/astrbot_plugin_dafeiyu_drawer/drawer.db
data/plugin_data/astrbot_plugin_dafeiyu_drawer/stickers/
```

只保存在本地，不会上传。

## 注意

- 表情包只按来源备注和文件名搜索，不做 OCR
- 主人身份优先读 `data/owner.json`，其次读 social 插件的 `admin_qq`
- 没有配置主人时，私聊会被当作主人；配置后严格按主人 QQ/UMO 判断
- 群里只收集主人的表情包，不收集其他人的
- 抽屉内容属于私人小事，不要在群里让 AI 复述
