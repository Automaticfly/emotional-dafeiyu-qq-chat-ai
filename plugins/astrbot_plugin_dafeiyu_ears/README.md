# 大肥鱼耳朵

让大肥鱼会点歌、随机听歌和分享歌曲。

默认只用本地音乐，不依赖任何第三方接口。

## 准备音乐

把音频放进：

```text
data/plugin_data/astrbot_plugin_dafeiyu_ears/music/
```

支持：

```text
.mp3  .flac  .m4a  .wav  .ogg  .aac  .opus
```

可以建子目录，扫描时会递归查找。

## 命令

```text
/本地点歌 晴天      按文件名关键词点歌
/本地听歌           随机放一首本地歌曲
/本地歌单           查看本地歌单
/本地分享 晴天      分享本地歌曲
```

本地命令和插件市场的「我想听歌！」分开：

- 在线/B 站点歌：用市场插件，直接说「我要听…」
- 本地音乐：用 `/本地点歌`、`/本地听歌`
- 两套工具名也不同：`local_music_play` / `local_music_search` 对 `find_in_bilibili` / `deliver_media`

## 发送方式

配置 `send_mode`：

| 值 | 行为 |
|---|---|
| `file` | 发文件，适合整首歌，默认 |
| `record` | 发语音条，适合短音频，受 QQ 语音时长限制 |
| `card` | 在线歌曲发 QQ 音乐卡片；本地歌曲回退为文件 |

## 在线搜索（可选）

在插件配置里填写 `meting_api`，例如：

```text
https://api.injahow.cn/meting/
```

填写后会：

- `/本地点歌` 本地没找到时在线搜索
- `/本地分享` 在线歌曲发音乐卡片
- `/本地听歌` 只放本地歌曲

第三方 Meting 接口的可用性和音乐版权由使用者自行确认。仓库不内置任何音乐资源。

## 听歌卡片

当主人分享 QQ 音乐卡片时，插件会把「主人分享了《歌名》」注入给模型，让她自然接一句，但不会假装自己真的听过音频。

## 数据

```text
data/plugin_data/astrbot_plugin_dafeiyu_ears/music/
```

只保存在本地，不会上传到 GitHub。

## 注意

- 默认不开启群聊点歌，避免刷屏
- 点歌有 10 秒冷却
- 整首歌建议用 `file`，语音条可能被 QQ 截断
- 在线接口只返回搜索结果和 URL，不缓存音乐文件
