# 大肥鱼涟漪记忆

一个专门记「碎事」的记忆池。

和日记不一样，涟漪记忆不追求完整、准确、永久。它更像人脑子里那些没什么用、但会被一句话勾起来的小事：哪天路过闻到桂花、随口说过想吃什么、群里谁提过一嘴的东西。

## 它怎么工作

每件小事进池子后会沿一条类似艾宾浩斯遗忘曲线的轨迹往下走：

```text
保留度
1.0 ┤ 新鲜（不提）
    │      ╲
0.6 ┤       ╲
    │        ╲   中部（被关键词勾一下才想起）
0.2 ┤         ╲
    │          ╲
0.0 ┤           ╲  沉底（不再主动想起）
    └──────────────────────── 时间
```

- **新鲜**：刚放进去，或者刚被想起过，太清楚了，不主动提。
- **中部**：有点印象又不深刻。聊天里再次撞见关键词、重复 4 个字或意思相近时，才会模糊地想起。
- **沉底**：已经想不起来了。要重新被提到（重复字数够、命中特殊词、或语义相似度够）才会被勾回中部，**下一次**才有机会被想起。

曲线用 `exp(-经过天数 / 记忆尺度)` 计算。默认尺度 1.8 天：

| 阶段 | 大约时间 |
|---|---|
| 新鲜 | 刚入池 ~1 天 |
| 中部 | 1 ~ 3 天 |
| 沉底 | 3 天以后 |

每想起一次，记忆尺度乘 1.75（间隔重复），最多到 10 天。所以被反复提起的事会淡得慢一点。

## 规定

1. 当天摘进池子的事，当天不会触发想起。
2. 想起时只给模糊印象：时间说法会变糊（前两天 / 前阵子 / 好久以前），具体时间、数字会被拿掉，内容也会随年龄截短。
3. 沉底的事被重新提到，会勾回中部，但不会当场想起。
4. 内置一整套屏蔽词：就是、这个、今天、早上、吃饭、睡觉…… 这些不会被当关键词，也不单独触发。
5. 同一会话 90 分钟内最多想起一次，避免一直翻旧账。
6. 只记碎事。重要承诺、长期偏好、情绪大事交给日记 2.0。

## 参数（按大肥鱼调过）

| 参数 | 默认 | 作用 |
|---|---|---|
| `base_scale_days` | 1.8 | 初始记忆尺度，越小忘得越快 |
| `fresh_retention` | 0.62 | 高于此值算新鲜，不主动提 |
| `mid_retention` | 0.16 | 低于此值算沉底 |
| `recall_min_overlap` | 4 | 重复 4 个字触发想起 |
| `revive_min_overlap` | 4 | 重复 4 个字把沉底勾回中部（想更严格改成 6） |
| `recall_similarity` | 0.8 | 字面相似度阈值 |
| `revive_similarity` | 0.8 | 判断「是不是同一件事」的阈值 |
| `recall_cooldown_minutes` | 90 | 想起冷却 |
| `special_keywords` | 空 | 特殊触发词，例如「火锅,猫,考试」 |

想让她忘得更快，就把 `base_scale_days` 调到 1.2；想留久一点就调到 3。

## 怎么进池子

- **自动摘录**：每天 03:00-06:00 读取最近 24 小时聊天，让模型挑 0-3 件小事入池。
- **她自己记**：对话里调用 `ripple_remember` 工具，把刚聊到的小事丢进去。
- **手动管理**：见下面的命令。

## 命令

| 命令 | 说明 |
|---|---|
| `/涟漪` | 查看新鲜 / 中部 / 沉底数量和冷却 |
| `/涟漪 列表` | 最近 20 条 |
| `/涟漪 列表 中部` | 只看中部 |
| `/涟漪 找回 <id>` | 手动把一条勾回中部 |
| `/涟漪 删 <id>` | 归档一条 |
| `/涟漪 摘录` | 立刻从最近 24 小时聊天里摘一次 |
| `/涟漪 记 <内容> \| <关键词>` | 手动放一件小事进池子，例如 `/涟漪 记 主人说楼下的桂花开了 \| 桂花,楼下` |

## 工具

| 工具 | 说明 |
|---|---|
| `ripple_remember` | 记一件日常小事，可带 2-4 个关键词 |
| `ripple_search` | 按关键词翻池子，返回模糊印象 |

## 数据

只写本插件自己的数据库：

```text
data/plugin_data/astrbot_plugin_dafeiyu_ripple/ripple.db
```

里面是涟漪池、最近 3 天聊天记录和冷却状态，不会写进 AstrBot 主数据库，也不会同步到别处。

## 和别的记忆插件的关系

| 插件 | 记什么 |
|---|---|
| LivingMemory | 长期事实、偏好、关系 |
| 记忆 2.0 | 日记、画像、日程 |
| 涟漪记忆 | 不重要、会淡、偶尔被勾起的碎事 |

三者互不替代。涟漪记忆刻意不追求准确，想查确凿的事应该用 `/lmem search` 或日记。
